# Ledgerly

Invoicing and billing management dashboard for tracking revenue, managing clients, and monitoring payment statuses.

## Features

- **Invoice Management** — Track Paid, Pending, Overdue, and Draft invoices
- **Client Directory** — Sidebar with quick client access
- **Filterable Table** — Sort and filter by status, amount, and due date
- **Amount Tracking** — See invoice totals at a glance
- **Responsive Layout** — Works on desktop and mobile

## Tech Stack

- **Framework:** Next.js 16
- **Language:** TypeScript
- **Styling:** CSS Modules
- **Font:** Geist

## Getting Started

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## Build

```bash
npm run build
npm start
```

## Status

Frontend dashboard UI. A foundation for connecting to a payment backend, email automation, and accounting integrations.
